## 📖 About This Repository

This repository contains assignments and exercises from the **Computer Programming (PROKOM)** course at UGM — my first semester introduction to programming using Python. It covers fundamental programming concepts that form the foundation for all future technical work.


## 🧠 Topics Covered

- Python syntax and basic data types (int, float, string, boolean)
- Variables and operators
- Conditional statements (`if`, `elif`, `else`)
- Loops (`for`, `while`)
- Functions and parameters
- Lists, tuples, and dictionaries
- String manipulation
- Basic input/output operations
- Introduction to modules and libraries
